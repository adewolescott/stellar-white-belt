# Stellar White Belt dApp

A decentralized payment application on the Stellar Testnet built with React, TypeScript, Horizon API, and Freighter Wallet.

## Features
- Freighter Wallet Connect & Disconnect
- Live XLM balance fetching via Stellar Horizon
- Send XLM payments on Testnet
- Transaction hash confirmation with Stellar Expert link

## How to Run Locally
1. Clone repository: \`git clone <REPO_URL>\`
2. Install dependencies: \`npm install\`
3. Start dev server: \`npm run dev\`
4. Switch Freighter extension to **Testnet**
